\section{Edge deployment design for a pathology lab}
\begin{enumerate}
\item \textbf{Scanner-side box (CPU / Jetson):} read pyramid lazily $\to$ thumbnail GMM tissue mask $\to$ 20$\times$ tiles
$\to$ 128\,px features $\to$ GMM QC $\to$ (a) QC report per slide with rejected-tile reasons and a ``rescan'' flag if the
rejected tissue fraction exceeds a limit; (b) component fractions and a priority score.
\item \textbf{Upload only kept tiles (or only slides that pass QC)} to the GPU server / cloud: 3--4$\times$ less data and compute.
\item \textbf{Heavy model} (U-Net/DeepLab for segmentation; foundation-model features + MIL for slide diagnosis) only on
kept tiles; TTA only on uncertain tiles.
\item \textbf{Monitoring}: the GMM log-likelihood distribution per slide is a free drift detector -- a new scanner or
stain protocol shifts it before accuracy drops.
\end{enumerate}
\keyidea{Edge = do the cheap, label-free, high-recall decisions next to the data; keep the expensive, label-hungry
decisions on the GPU. The GMM gate is the boundary between the two.}
